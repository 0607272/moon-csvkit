# MoonBit Hackathon 2026 项目申报

## 1. 项目名称

moon-csvkit

## 2. 项目简介

moon-csvkit 是使用 MoonBit 独立实现的 CSV 数据处理工具，包含可复用的解析与序列化库、表格数据模型、CSV 与 JSON Lines 转换能力以及命令行工具。项目重点处理引号字段、字段内换行、转义引号、CRLF、空字段和列数校验等实际数据问题。

## 3. 项目方向、通用性说明

项目按“原创新项目”申报，方向为通用 MoonBit 数据处理基础库及开发工具。CSV 广泛用于数据交换、配置、测试数据和批量导入导出；项目同时提供库接口与 CLI，可用于 MoonBit 应用，也可用于本地脚本和 CI 数据校验。

## 4. 预期使用场景

1. 业务系统导入用户提交的 CSV，在处理前检查引号格式和记录列数，阻止异常数据进入后续流程。
2. 数据清洗工具解析含逗号、换行或双引号的字段，并按指定分隔符重新序列化，避免逐行切分造成数据损坏。
3. MoonBit 服务在 CSV 与 JSON Lines 之间转换数据，保留表头顺序，便于日志处理、流式交换和程序间集成。
4. 项目在 CI 中调用命令行校验 CSV 测试数据，在格式错误或字段数量变化时及时失败。

## 5. 拟实现的核心功能

- 支持常用 CSV 语法的解析器，以及严格和宽松两种记录列数处理模式。
- 自动处理字段引用、内嵌分隔符与换行、双引号转义、CRLF 和空字段。
- 提供 CSV 序列化和自定义单字符分隔符输出。
- 提供带可选表头的表格数据模型，以及 CSV 与 JSON Lines 双向转换。
- 提供 `check`、`format`、`to-jsonl`、`from-jsonl` 命令和可运行示例。
- 配置自动化检查、构建和测试，并持续补充异常输入测试与使用文档。

## 6. 项目来源

本项目为原创项目，由申报者使用 MoonBit 独立设计和实现，不是其他 CSV 项目的 Fork、移植或代码复制。项目功能边界是轻量、可复用的 CSV/JSON Lines 数据处理库与 CLI。

## 7. 移植或参考项目说明

不适用。本项目不是移植项目。开发期间对 MoonBit 生态中的 NyaCSV 进行了独立调研，并向其提交了 Issue 和 PR；该贡献不构成 moon-csvkit 的代码基础或申报主体。相关记录见 [NyaCSV 上游维护记录](upstream-maintenance.md)。
